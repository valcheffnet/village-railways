# Village Railways

A Fabric mod that links villages with minecart railway lines, built only from vanilla blocks. It runs on the server
alone, so players join with a plain vanilla client.

Lines run in long straight segments and stay level: shallow hills are cut through with an open trench, deeper ones
with a tunnel, and water or drops are crossed on a bridge. Each line ends at a small station with a minecart
dispenser.

Work in progress, nothing released yet. Minecraft 26.3, Fabric, server side.
